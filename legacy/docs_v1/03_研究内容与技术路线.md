# 研究内容与技术路线

## 3. 研究内容与技术路线

### 3.1 研究目标

本课题面向 ICL（Implantable Collamer Lens，可植入式隐形眼镜）植入术后拱高（Vault）预测问题，拟构建一个融合术前 **AS-OCT 图像、UBM 图像及临床生物测量参数** 的多模态深度学习模型，实现术后 Vault 的连续值预测，并进一步为术后风险分层与 ICL 尺寸选择提供辅助支持。

具体而言，本研究希望解决以下几个核心问题：

1. 如何从术前多源异构数据中提取与术后 Vault 相关的高判别性特征；
2. 如何建模不同模态之间的互补关系与非线性耦合关系；
3. 如何在真实临床样本有限的条件下，提高模型训练稳定性与泛化能力；
4. 如何将预测模型进一步扩展为可展示、可验证、可落地的原型系统。

------

### 3.2 研究内容

围绕上述目标，本课题的研究内容主要包括以下四个方面。

#### 3.2.1 ICL 术后 Vault 预测问题建模

首先，从临床应用需求出发，对 ICL 术后 Vault 预测任务进行形式化定义。将术前 AS-OCT 图像、UBM 图像及临床参数作为联合输入，将术后实际 Vault 值作为监督标签，将该问题抽象为一个面向临床辅助决策的多模态连续值回归问题。

在此基础上，进一步分析传统经验公式和统计回归方法在复杂解剖结构表征、非线性关系建模以及多模态信息利用方面的局限性，为引入深度学习方法提供理论依据。

#### 3.2.2 多模态特征提取与融合模型设计

针对 ICL 术后 Vault 形成受多种解剖因素共同影响的特点，构建多模态联合建模框架。该框架分别对 AS-OCT 图像、UBM 图像和临床参数进行特征编码，并在高层特征空间中实现交互与融合，最终输出术后 Vault 预测值。

其中：

- AS-OCT 分支用于提取前节浅层解剖结构特征；
- UBM 分支用于提取睫状沟及后房相关深层结构特征；
- 临床参数分支用于编码前房深度、白到白距离、轴长等结构化测量信息；
- 融合模块用于建模不同模态之间的互补信息与耦合关系；
- 回归预测头用于完成术后 Vault 的连续值预测。

#### 3.2.3 基于公开数据预训练的迁移学习策略研究

考虑到真实 ICL 临床数据样本量有限、采集成本较高，本研究拟采用“**公开数据预训练 + 临床任务迁移微调**”的两阶段训练策略。

首先，利用公开眼科数据集对视觉主干网络进行预训练，使模型学习眼科前节图像中的通用结构表征；随后，将预训练得到的编码器迁移到 ICL 术后 Vault 预测任务中，与 UBM 分支及临床参数分支联合训练。通过该策略提升模型在小样本场景下的训练稳定性和特征提取能力。

#### 3.2.4 原型系统构建与模型验证

在算法模型构建基础上，进一步搭建 ICL 术后 Vault 预测原型系统，实现数据输入、模型推理、结果展示与基础可视化分析等功能。通过原型系统验证模型的工程可行性和应用展示能力，为后续与医院临床场景对接奠定基础。

同时，在模型验证阶段，将从连续值回归性能和临床风险分层表现两个层面开展实验分析，以全面评估模型的有效性与实用性。

------

### 3.3 技术路线

本课题整体技术路线可概括为：**问题定义 → 数据准备 → 公共数据预训练 → 多模态联合建模 → 模型训练与评估 → 原型系统实现**。具体如下。

#### 3.3.1 数据准备与预处理

首先对项目涉及的数据进行整理与预处理。对于公开数据集，完成图像清洗、格式统一、尺寸标准化、标签匹配等工作；对于后续真实临床数据，完成 AS-OCT、UBM 与临床参数的样本级对应、缺失值检查和数据规范化处理。

在影像数据层面，必要时引入辅助分割或 ROI 提取模块，以增强模型对关键解剖区域的关注能力，减少无关背景干扰。

#### 3.3.2 公开眼科数据预训练

在公开眼科数据集上对视觉编码器进行预训练，使其先学习眼科图像中的通用结构特征。该阶段的目标不是直接完成 Vault 预测，而是获得对前节结构更敏感的初始特征提取器，为后续真实任务训练提供更优初始化。

#### 3.3.3 多模态预测模型构建

在预训练基础上，构建 ICL 术后 Vault 多模态预测模型。模型采用多分支结构：

- AS-OCT 编码分支提取浅层结构表征；
- UBM 编码分支提取深层结构表征；
- 临床参数编码分支提取结构化数值特征；
- 特征融合模块实现多模态联合表示学习；
- 回归头输出最终 Vault 预测值。

在模型设计上，将优先建立稳定可复现的融合基线模型，并在此基础上逐步探索更强的交互式融合机制，以提升模型对复杂解剖关系的建模能力。

#### 3.3.4 模型训练与优化

采用监督学习方式训练多模态模型，以真实术后 Vault 值作为回归目标。训练过程中，通过回归损失函数约束预测误差，并结合验证集表现对模型参数进行调优。必要时引入预训练初始化、正则化、早停等策略，以减轻过拟合风险并提升模型泛化性能。

#### 3.3.5 模型评估与结果分析

模型评估分为两个层面：

1. **回归性能评估**
    使用 MAE、RMSE、R² 等指标衡量模型对术后 Vault 连续值的预测能力。
2. **临床应用评估**
    基于临床阈值对预测结果进行区间划分，评估模型在低 Vault 风险、高 Vault 风险及合理区间判别中的表现，从而增强模型结果的临床解释意义。

同时，结合误差分析、可视化结果展示和不同模块对比实验，对模型有效性进行系统分析。

#### 3.3.6 原型系统实现

在模型稳定后，进一步构建原型系统，实现基础的人机交互流程，包括样本输入、自动推理、结果输出及可视化展示。该系统既可作为阶段性研究成果展示平台，也可为后续真实临床环境下的部署与验证提供工程基础。

------

### 3.4 关键技术难点

本课题的主要技术难点包括：

1. **多模态数据异构性强**
    AS-OCT、UBM 和临床参数在数据形式、尺度和信息密度上差异明显，如何实现有效联合建模是核心难点之一。
2. **样本量有限与过拟合风险**
    真实临床数据获取难度较大，小样本条件下深度模型易出现过拟合，需要合理利用预训练和迁移学习策略。
3. **模态间非线性耦合复杂**
    术后 Vault 受多种解剖结构和临床参数共同影响，不同模态之间存在复杂交互关系，传统浅层模型难以刻画。
4. **临床可解释性与工程可落地性要求较高**
    模型不仅要具备较高预测精度，还需要具有一定的临床解释意义，并能进一步融入原型系统验证流程。

------

### 3.5 预期成果

通过本课题研究，预期取得以下成果：

1. 建立 ICL 术后 Vault 预测的多模态问题建模框架；
2. 设计并实现一个融合 AS-OCT、UBM 与临床参数的深度学习预测模型；
3. 构建“公开数据预训练 + 临床任务微调”的训练流程；
4. 完成模型性能评估、消融分析与结果可视化；
5. 开发一个具备基础预测与展示能力的原型系统；
6. 为后续论文撰写、专利凝练和临床应用转化提供研究基础。
